# DevPilot AI

AI-powered backend engineering workspace built with Spring Boot, Spring AI, and the Model Context Protocol (MCP).

## Features

* 🤖 AI Chat Assistant
* 🛠️ MCP Tool Calling
* ⚡ Spring Boot Code Generator
* 🗄️ SQL Optimization Assistant
* 🧪 JUnit Test Generator
* 📘 OpenAPI/Swagger Generator
* 🏗️ Architecture Recommendation Engine
* 🔒 JWT Authentication
* 🐳 Docker Support

## Tech Stack

* Java 21
* Spring Boot 3.5
* Spring AI
* Model Context Protocol (MCP)
* PostgreSQL
* Spring Security
* Maven
* Docker
* GitHub Actions
